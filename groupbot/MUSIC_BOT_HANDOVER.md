دستورات اصلی (توی گروه):
- «پخش [نام]» / «play [name]» → پخش موزیک
- «توقف» / «stop» → توقف
- «رد کن» / «skip» → بعدی
- «صف» / «queue» → صف
- «پاک کن صف» / «clear» → پاک صف
- «صدای بیشتر» / «volume up»
- «قطع کن» / «leave» → خروج از ویس‌چت

دستورات اشتراک (توی PV):
- «اشتراک من» / «mysub» → وضعیت
- «خرید اشتراک موزیک» → به مدیریت
- «تمدید» → تمدید

⚠️ هشدارهای مهم
═══════════════════════════════════════════════════════════════

⚠️ ۱. pytgcalls با PTB conflict داره
   - routing جدا لازمه
   - handler ها توی group -10 یا بالاتر

⚠️ ۲. proxy / VPN
   - pytgcalls از VPN پشتیبانی نمی‌کنه
   - اگه VPN فعاله، موزیک پخش نمی‌شه

⚠️ ۳. RAM
   - pytgcalls + ffmpeg → ~500 MB اضافه
   - با ۵ گروه → ~1 GB
   - با ۱۰۰ گروه → ~5 GB

⚠️ ۴. Storage
   - هر آهنگ ~۳-۵ MB
   - cache قابل تنظیم
   - حتماً cleanup خودکار بذار

⚠️ ۵. YouTube blocking
   - yt-dlp گاهی IP block می‌شه
   - fallback: لینک مستقیم یا SoundCloud
