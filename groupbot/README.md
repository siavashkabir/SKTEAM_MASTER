# 🔐 فصل ۱: کلیدها (API Keys)

## کلیدها چی هستن؟

ربات به سرویس‌های بیرونی وصل می‌شه. هر سرویس برای امنیت، یه **کلید** بهت می‌ده که مثل پسورد اکانته.

---

### 🔑 کلید HuggingFace (کلید اصلی AI - رایگان)

**برای چیه؟**
- این کلید به ربات اجازه می‌ده از مدل‌های AI **رایگان** HuggingFace استفاده کنه
- مدل‌های رایگانش: Llama-3.3-70B، Qwen-2.5-72B و...

**چرا مهمه؟**
- رایگانه (بدون پرداخت)
- ۱۰۰۰ درخواست در روز
- یکی از بهترین مدل‌های رایگان

**چطور کلید بگیرم؟**
1. برو https://huggingface.co/join
2. با ایمیل یا گوگل ثبت‌نام کن
3. برو https://huggingface.co/settings/tokens
4. دکمه Create new token رو بزن
5. نوع Read رو انتخاب کن
6. اسم بذار: Skteam
7. دکمه Create token رو بزن
8. کلید شبیه hf_xxxxx رو کپی کن

**چطور توی ربات وارد کنم؟**
- پنل → 🖥 مدیریت سیستم → 🤖 مدیریت AI → 🔑 HuggingFace
- کلید رو پیست کن و بفرست

---

### 🔑 کلید OpenRouter (کلید پشتیبان AI - پولی)

**برای چیه؟**
- وقتی HuggingFace خطا بده یا محدودیتش تموم بشه
- OpenRouter یه واسطه‌ست که به کلی مدل پولی دسترسی می‌ده

**چرا مهمه؟**
- پشتیبان برای مواقع اضطراری
- ارزون: با ۱ دلار میلیون‌ها توکن

**چطور کلید بگیرم؟**
1. برو https://openrouter.ai
2. ثبت‌نام کن
3. برو https://openrouter.ai/keys
4. Create Key رو بزن
5. کلید شبیه sk-or-v1-xxxxx رو کپی کن

**چطور توی ربات وارد کنم؟**
- پنل → 🖥 مدیریت سیستم → 🤖 مدیریت AI → 🔑 OpenRouter

---

## ❓ چرا دو تا کلید AI داریم؟

**Fallback خودکار:**
1. اول HuggingFace مدل اول (رایگان)
2. اگه خطا داد → مدل دوم HF (رایگان)
3. اگه خطا داد → مدل سوم HF (رایگان)
4. اگه همه خطا دادن → OpenRouter (پولی)

**نتیجه:** ۹۹٪ اوقات رایگان، پول فقط اضطراری.

# 🤖 فصل ۲: مدیریت AI

مسیر: پنل → 🖥 مدیریت سیستم → 🤖 مدیریت AI

## دکمه‌ها:

**🔑 HuggingFace** — تنظیم کلید HF
**🔑 OpenRouter** — تنظیم کلید OR
**🌐 فعال سراسری** — کل AI رو روشن/خاموش می‌کنه
**🧪 تست HuggingFace** — اتصال HF رو چک می‌کنه
**🧪 تست OpenRouter** — اتصال OR رو چک می‌کنه
**📋 مدل‌های HuggingFace** — لیست مدل‌ها + افزودن/حذف

## چطور AI رو برای یه گروه فعال کنم؟

1. پنل → ⚙️ تنظیمات این گروه
2. دکمه 🤖 پاسخ هوشمند رو بزن → ✅ فعال بشه
3. شخصیت و فرکانس رو تنظیم کن

## شخصیت‌های AI:

- 😄 **طنز** — باحال، شوخ، فحش ملایم
- 🙂 **مؤدب** — محترمانه، بدون فحش
- 🤣 **بامزه** — طنز کودکانه
- 😎 **خفن** — مغرور، باکلاس
- 😈 **خیلی خیلی خفن** — رک، بی‌تعارف

## فرکانس پاسخ:

- 📊 **فقط منشن** (پیش‌فرض) — فقط وقتی صدا بزنی
- 📊 **30%** — ۳۰٪ پیام‌ها
- 📊 **50%** — نصف پیام‌ها
- 📊 **همه پیام‌ها** — همه

## حالت بزرگسال:

- ✅ فعال — شوخی بزرگسالانه مجاز
- ❌ غیرفعال — مؤدب

**نکته:** AI هرگز فحش رکیک جنسی یا توهین به خانواده نمی‌گه.

# 🖥 فصل ۳: مدیریت سیستم

مسیر: پنل → 🖥 مدیریت سیستم

## 🖥 وضعیت سیستم
CPU، RAM، Disk، آپ‌تایم و آمار ربات.

## 👥 بانک کاربران
Export کاربران به CSV، JSON، SQLite.

**چرا مهمه؟** اگه بخوای کاربرا رو به ربات تبلیغاتی منتقل کنی.

## 📜 لاگ‌ها
فایل لاگ کامل رو به پیوی می‌فرسته.

## 🚫 اسپم‌ترکر
- کاربرایی که ۳ بار توی گروه‌های مختلف بن شدن → Global Ban خودکار
- حد نصاب قابل تنظیم

## 💾 بکاپ فوری
بکاپ دستی از دیتابیس.

**بکاپ خودکار:** هر ۶ ساعت، بکاپ‌های قدیمی‌تر از ۷ روز خودکار پاک می‌شن.

## 🗄 دیتابیس
- 📊 حجم — اندازه دیتابیس
- 📈 آمار جداول
- 🗜 VACUUM — فشرده‌سازی (کم‌کردن حجم، افزایش سرعت)
- 🔍 بررسی سلامت
- 📤 Export دیتابیس
- ⚠️ پاکسازی رکوردهای قدیمی

## 🧹 پاکسازی
- 📄 برش لاگ (آخرین ۵۰۰۰ خط)
- 🗑 حذف کامل لاگ
- 💾 پاکسازی بکاپ‌های قدیمی
- 🧽 پاک کردن فایل‌های temp

## 🌐 شبکه
- 🏓 تست اتصال تلگرام (ping)
- 🌐 تست SIGHTENGINE
- 📡 تست DNS

## ⚙️ تنظیمات سیستم (سراسری)
پیش‌فرض برای همه گروه‌ها:
- ⏱ Cooldown دستورات
- 🗑 حذف پنل
- ⏳ انقضای پنل
- 💬 حذف پیام expire
- 🔔 هشدار قبل از ری‌استارت
- ⏱ تأخیر ری‌استارت
- 🚫 Global Ban خودکار
- 🔐 دسترسی سودو به /userinfo

## 🔄 ری‌استارت ربات
با تأیید + هشدار به گروه‌ها + تأخیر.

# ⚙️ فصل ۴: تنظیمات این گروه

مسیر: پنل → ⚙️ تنظیمات این گروه

**برای هر گروه جداگانه.**

- ⏱ **Cooldown** — فاصله بین دستورات (30s)
- 🗑 **حذف پنل** — حذف خودکار پنل (30s)
- ⏳ **انقضای پنل** — بعد این زمان منقضی می‌شه (3m)
- 💬 **حذف پیام expire** — حذف پیام «زمان به پایان رسید»
- 🤖 **پاسخ هوشمند** — AI فعال/غیرفعال
- 🎭 **شخصیت** — انتخاب شخصیت
- 📊 **فرکانس** — چطور پاسخ بده
- 🔞 **حالت بزرگسال** — بزرگسالانه
- 💬 **حذف جواب AI** — حذف خودکار جواب‌ها

# 📞 فصل ۵: پشتیبان و بازیابی

## بازیابی از بکاپ:
pkill -f "main.py"
mv ~/groupbot ~/groupbot_broken_$(date +%Y%m%d)
cd ~
tar -xzf ~/storage/shared/"ربات مدیریت گروه"/backups/groupbot_FULL_backup_YYYYMMDD_HHMMSS.tar.gz
cd ~/groupbot && source venv/bin/activate && nohup python3 -u main.py > ~/groupbot_bot.log 2>&1 &

pkill -9 -f "main.py" ; sleep 3

sleep 8
tail -n 15 ~/groupbot_bot.log
