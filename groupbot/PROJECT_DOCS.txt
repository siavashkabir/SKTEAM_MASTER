🔧 بخش ۱۱: حل مشکلات رایج
══════════════════════════════════════════════════════════════════

【ربات کرش یا Timeout】
    → VPN قطع شده. کاربر باید VPN رو روشن کنه.

【دکمه‌ای کار نمی‌کنه】
    → grep -n "callback_data" → چک کن prefix در whitelist و pattern هست.
    → توی middleware.py، whitelist رو چک کن.

【خطای UnboundLocalError】
    → if/import محلی قبل از استفاده. از بالای تابع import کن.

【خطای NameError: name 'X' is not defined】
    → متغیر توی handler تعریف نشده. مثلاً 'data' → 'query.data'

【خطای IndentationError】
    → اسکریپت قبلی ساختار try/except رو خراب کرده. از بکاپ برگردون.

【خطای ApplicationHandlerStop not supported】
    → block=False رو از middleware حذف کن.
